    Early days. Real ambition.

    One shared discovery layer.

    SIN is an early-stage project for adult creator discovery. The vision brings together a directory, browser tools, AI agent plugins, and search integrations so creators can be found in more places.

    This repository includes the public name list and a browser name-highlighter prototype. Full creator profiles, integrations, and paid visibility are still planned.

    The proposed $SIN token would support creator registration and participation. Token integration and keyword pricing are still being designed; this repository provides no token implementation or verified contract address.
